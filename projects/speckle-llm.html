AskBIM

Natural-language questions on building models, since 2023.

  • Python
  • FastAPI
  • Speckle (GraphQL, webhooks, specklepy)
  • Ollama
  • Llama 3.1
  • SQLite
Overview

Most people on a building project never open the 3D model, yet they still have questions about it. AskBIM allows them to ask in a comment, for example how many doors have no fire rating, and replies with the answer, the exact data behind it and a link that shows the relevant elements in the model. It also checks each new version of the model against the project's written requirements.

ResultThe conclusion from 2023 still holds: the language model was never the difficult part. Obtaining clean, structured data from the design tools is.

The problem

Most people on a project never open the model, yet they still have questions about it: the insulation value of a panel, the number of doors without a fire rating, or whether the latest version still meets the specification.

The solution

In 2023 I connected Speckle, an open platform for sharing 3D building models, to a large language model so that a project team could query a model in plain language. AskBIM is the 2026 rebuild. It runs on a local Llama model through Ollama, so model data and project documents never leave the machine.

AskBIM operates within Speckle's comment threads. A question about a selected element is answered from the element's properties and any attached specification PDF, with page references, and questions about the whole model are answered in the same way. Each new version is checked against rules derived from the specification. Every failing rule receives its own thread highlighting the affected elements, and AskBIM replies in that thread once a later version resolves them.

The language model never performs calculations and never writes the database query. It completes a structured query plan that is restricted to existing field names. Code validates and corrects the plan, executes it, and includes the exact query and result in every reply. The model can propose rules from the specification, but none is applied until a person approves it.

AskBIM also reads native IFC files (IFC2X3, IFC4 and IFC4X3) locally, without a platform or an account, and writes the findings of a check as BCF topics that other BIM tools can open.

I also built a custom connector between Speckle and Revit.

Features

  • Answers questions about a selected element from its properties and any attached specification PDF, with page references
  • Answers questions about the whole model, such as counts, totals and breakdowns per floor
  • Keeps every element of the latest version of each model in a local SQLite database
  • The language model only fills in a structured query plan; code checks and corrects it and runs it as a safe database query
  • Each reply shows the exact query and result, and a link that opens exactly those elements in the Speckle viewer
  • Suggests rules from specification PDFs; a person approves them before they run
  • Checks every new model version and opens one pinned thread per failing rule, highlighting the elements in the viewer
  • Replies "Resolved" when a later version fixes the problem
  • Missing values are reported as missing, never invented, and page references are checked against the documents
  • Runs on a local Llama model through Ollama, so model data and documents never leave the machine
  • Works with both Speckle data formats (version 2 Revit parameters and version 3 properties)
  • Reads native IFC files (IFC2X3, IFC4 and IFC4X3) locally, without a platform or an account
  • Writes the findings of an IFC check as BCF 2.1 topics that other BIM tools can open
  • Webhook server with signature checks and protection against duplicate retries; a command line for indexing, questions and checks; Docker setup with GPU support

Glossary

BIM
Building Information Modelling: designing a building as a shared 3D model that also holds data about every part, instead of separate drawings.
Revit
Autodesk's main software for designing buildings as BIM models. It is widely used by architects and engineers.
IFC
An open file format for building models that any BIM software can read. It is maintained by buildingSMART.
BCF
An open format for passing model issues, such as clashes, between different BIM programs.
Speckle
An open platform for sharing and viewing 3D building models online.
Language model
An AI model that reads and writes text, such as the one behind ChatGPT. Llama is a freely available model that can run on a local computer.
