AskBIM

Natural-language questions on building models.

Overview

AskBIM answers plain-language questions about a 3D building model within the comment threads of Speckle, an open platform for sharing 3D building models. It runs on a local Llama model through Ollama, so model data and project documents stay on the machine. First built in 2023 and rebuilt in 2026.

A question about a selected element or about the whole model is answered from the element properties and any attached specification PDF, with page references. Each new model version is checked against rules derived from the specification. Every failing rule receives its own thread highlighting the affected elements, and the thread is updated once a later version resolves them.

The language model performs no calculations and writes no database queries. It completes a structured query plan restricted to existing field names. Code validates and executes the plan and includes the exact query and result in every reply. Rules proposed by the model are applied only after a person approves them.

Native IFC files (IFC2X3, IFC4 and IFC4X3) are read locally, without a platform or an account, and the findings of a check are written as BCF topics.

The project also includes a custom connector between Speckle and Revit.

Features

  • Answers questions about a selected element from its properties and any attached specification PDF, with page references
  • Answers questions about the whole model, such as counts, totals and breakdowns per floor
  • Keeps every element of the latest version of each model in a local SQLite database
  • The language model only fills in a structured query plan; code checks and corrects it and runs it as a safe database query
  • Each reply shows the exact query and result, and a link that opens exactly those elements in the Speckle viewer
  • Suggests rules from specification PDFs; a person approves them before they run
  • Checks every new model version and opens one pinned thread per failing rule, highlighting the elements in the viewer
  • Replies "Resolved" when a later version fixes the problem
  • Missing values are reported as missing, never invented, and page references are checked against the documents
  • Runs on a local Llama model through Ollama, so model data and documents never leave the machine
  • Works with both Speckle data formats (version 2 Revit parameters and version 3 properties)
  • Reads native IFC files (IFC2X3, IFC4 and IFC4X3) locally, without a platform or an account
  • Writes the findings of an IFC check as BCF 2.1 topics that other BIM tools can open
  • Webhook server with signature checks and protection against duplicate retries; a command line for indexing, questions and checks; Docker setup with GPU support

Glossary

BIM
Building Information Modelling: designing a building as a shared 3D model that also holds data about every part, instead of separate drawings.
Revit
Autodesk's main software for designing buildings as BIM models. It is widely used by architects and engineers.
IFC
An open file format for building models that any BIM software can read. It is maintained by buildingSMART.
BCF
An open format for passing model issues, such as clashes, between different BIM programs.
Speckle
An open platform for sharing and viewing 3D building models online.
Language model
An AI model that reads and writes text, such as the one behind ChatGPT. Llama is a freely available model that can run on a local computer.
